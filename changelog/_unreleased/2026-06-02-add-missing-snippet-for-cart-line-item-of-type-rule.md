# Administration
* Added missing `global.sw-condition-generic.*` snippet keys in `en-GB.json` and `de-DE.json` for rule conditions rendered via `sw-condition-generic`. Without these, the option labels were displayed as raw snippet paths. Added entries for: `dayOfWeek`, `cartLineItemOfType`, `cartTaxDisplay`, `cartTotalPurchasePrice`, `promotionCodeOfType`, `cartLineItemProductStates`.
